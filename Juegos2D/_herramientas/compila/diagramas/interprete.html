Cómo funciona el intérprete

Primero se calcula TODO de golpe (interpretar) y luego se enseña paso a paso (animación). Así la animación es sencilla.

1. Cartas elegidas[ +7, ↻2, ×2 ]
(en el orden de selección)
➜
2. interpretar(cartas)recorre las cartas, calcula x con aplicarCarta() y apunta cada paso
➜
3. Lista de pasos{linea:0, x:0}
{linea:1, x:7}
{linea:2, "2 veces"}
{linea:3, x:14}
{linea:3, x:28}
4. actualizarEjecucion(dt)cada ~0,4 s muestra el siguiente paso: resalta la línea, escribe el comentario // x = 14 y actualiza el número grande. Cada paso va un poco más rápido que el anterior.
➜
5. terminarEjecucion()suma el resultado al puntaje, quita las cartas usadas y roba nuevas

Los intérpretes reales (como el de JavaScript o Python) también leen las instrucciones una a una, en orden, y van cambiando el valor de las variables.
