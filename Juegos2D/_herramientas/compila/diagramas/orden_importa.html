La idea central del juego: el orden importa

Las mismas cartas, en distinto orden, dan resultados muy distintos. Igual que las instrucciones de un programa real.

Orden A: primero multiplicar
let x = 0;
x *= 3; // x = 0
x += 7; // x = 7
x = x * x; // x = 49
Resultado: 49
Orden B: primero sumar
let x = 0;
x += 7; // x = 7
x *= 3; // x = 21
x = x * x; // x = 441
Resultado: 441 (¡9 veces más!)

Estrategia: sumar al principio (para tener algo que multiplicar), multiplicar después y dejar el cuadrado para el final. Los bucles y las librerías cambian esta regla… y descubrir cómo es lo divertido. Esto entrena justo lo que más cuesta al empezar a programar: seguir el flujo de ejecución y el valor de las variables línea a línea (la "prueba de escritorio").
